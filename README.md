# Braiding Applet

Interactive 3D explorer for how an idealized circular (maypole) braiding machine lays yarns onto a
mandrel, and how the resulting yarn paths relate to the differential geometry of the surface and the
mechanics of the yarns.

**Live:** https://vaitkusm.github.io/braiding-applet/

> Work in progress. See [`docs/PLAN.md`](docs/PLAN.md) for the implementation plan.
